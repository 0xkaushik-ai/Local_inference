GET STARTED

          
Your local AI, connected.

        

        
      

      

        DeviceBench runs on your computer and checks a local AI server. Keep its
        terminal open while you use this workspace.
      

      
    
        
  1. 
          Start your AI server
          
    
            Start Ollama or an OpenAI-compatible local server. Install models
            through that server, then run Local AI Doctor to refresh the list.
          
    
        
    2. 
        
  2. 
          Choose the right connection
          
    
            This workspace is using
            your configured endpoint. Match the
            Server API selection to your runtime.
          
    
          
    
            To change the address, stop DeviceBench with Ctrl+C and launch it
            again. From an environment where DeviceBench is installed:
          
    
          
    devicebench serve --endpoint http://127.0.0.1:11434
    
          
    For a local OpenAI-compatible server, use its actual port:
    
          
    devicebench serve --endpoint http://127.0.0.1:1234 --protocol openai
    
          
    
            If running from source, use python -m devicebench in
            place of devicebench, with your repository’s
            src directory on PYTHONPATH.
          
    
        
    3. 
        
  3. 
          Check only what you need
          
    
            Doctor reads your setup. Model & Context estimates requirements
            where metadata is available. App Compatibility sends small test
            requests and may load models. It checks tool-call output without
            executing functions.
          
    
        
    4. 
        
  4. 
          Keep your results
          
    
            Download HTML for a readable report or JSON for further analysis.
            Changing settings requires a new check; reports are matched to the
            settings that produced them.
          
    
        
    5. 
      

      

        Supported connections and preview limits
        

          V1 supports HTTP servers on your own computer, without authentication.
          Remote servers and authenticated endpoints are outside this preview.
          Hardware information may be unavailable on some devices.
        

        

          Linux has been tested locally. Windows and macOS validation is
          pending. Estimates are guidance; compatibility results describe the
          requests checked, not overall app quality.
